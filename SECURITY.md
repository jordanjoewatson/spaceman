# Security Policy

## Supported versions

Security fixes are provided for the latest released version of Spaceman.

## Reporting a vulnerability

Please do not report security vulnerabilities in a public GitHub issue.

Use GitHub's [private vulnerability reporting](https://github.com/jordanjoewatson/spaceman/security/advisories/new)
to share the issue.

Include as much information as possible such as:
- Description of the issue
- How to reproduce the issue

For ordinary bugs and feature requests, use the repository's standard issue
templates instead.
